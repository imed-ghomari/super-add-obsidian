## SuperAdd 1.1.3 — review fixes

A small follow-up addressing the last remaining Obsidian community review notes. No new features to learn.

### What you'll notice
- Nothing visual — the task window, preview, templates, and searchable settings all work exactly as in 1.1.2. Due-time formatting (e.g. `09:05`) behaves identically.

### Under the hood
- Time formatting no longer depends on newer JavaScript library features, so the code checks cleanly against older targets too.
- This version still requires **Obsidian 1.13.1 or newer**. Your tasks and settings carry over unchanged.

### Action needed
- None. Just update.
