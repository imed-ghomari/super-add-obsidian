## SuperAdd 1.1.0 — searchable settings

Find any SuperAdd option in seconds. Settings now work with Obsidian's global **Settings search**, plus quick filters inside the plugin page.

### What's new for you
- **Global search finds everything**: press `Ctrl/Cmd + ,`, type in the Settings search box, and try `due`, `recurrence`, `template`, `default folder`, or `natural language` — matching SuperAdd rows light up and jump into view.
- **Filter inside Properties and Templates**: each section has its own search box (e.g. type a property name to narrow a long list).
- **New General section**: `Default folder` (folder picker — where new tasks go when you don't pick one) and `Enable natural language processing` are now visible settings instead of hidden defaults.
- **Clearer editing**: Properties and Templates use native add / delete / drag-to-reorder rows. Tap a property row to edit it.
- **Inline validation**: if a due/recurrence property name is empty or clashes with another property, you'll see the problem right under the field instead of a pop-up.
- **Works everywhere**: same experience on desktop and mobile. Older Obsidian versions keep the previous settings layout automatically.

### How to try it
1. Update to 1.1.0.
2. Open Settings → search `due` → open SuperAdd's **Due property name**.
3. In SuperAdd settings, try the **Search properties…** and **Search templates…** boxes.
4. Set **Default folder** to your tasks folder (e.g. `Tasks`).

### Compatibility
- Searchable settings light up on Obsidian 1.13.0 and newer.
- Older Obsidian versions (back to 1.4.0) keep working with the classic layout — no action needed.
