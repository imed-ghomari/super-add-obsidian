## SuperAdd 1.0.0 — first release

Welcome to SuperAdd! Create richly structured tasks from a single natural-language line.

### What you can do
- Open **Create Task** (command palette or `+` ribbon icon) and type like:
  - `Call Alex tomorrow 3pm #work due next week`
  - `Team sync next Fri 3pm every week`
- SuperAdd picks out the title, tags, time estimate, due date/time, and recurrence, and shows a **live preview** before you save.
- Define your own **Properties** in Settings (text, number, checkbox, list/tags, date, date & time) — SuperAdd recognises them inline by name or value.
- Add **Templates** (markdown files with frontmatter) — new notes keep the template's frontmatter order, and anything you typed overrides the template.
- Quick link insertion: type `-` at the start of a word to pick a file and insert a `[[link]]`.
- Choose the destination folder when creating the task.

### How to start
1. Go to Settings → SuperAdd → **Properties** and add the properties you use (e.g. `priority`, `due`, `tags`).
2. Optionally add **Templates** pointing at notes with the frontmatter you want.
3. Run **SuperAdd: Create Task** and type your task line.

### Compatibility
- Works on desktop and mobile.
- Requires Obsidian 1.4.0 or newer.
